# Farsi Keyboard Fix 2.0.0

نسخه بازطراحی‌شده برای Firefox با تمرکز روی اجرای مطمئن‌تر.

## تغییرات

- Manifest V2 برای سازگاری بهتر با Firefox
- صفحه تنظیمات مستقل
- فعال/غیرفعال کردن افزونه
- فعال/غیرفعال کردن جایگزینی خودکار
- تعریف میانبر سفارشی توسط کاربر
- منوی راست‌کلیک
- پیشنهاد جایگزینی به‌جای تغییر اجباری در حالت خودکار خاموش
- تشخیص محافظه‌کارانه برای کاهش خطای مثبت
- عدم پردازش فیلد رمز عبور
- عدم ارسال متن به اینترنت
