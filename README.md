# Farsi Keyboard Fix — Firefox

افزونه‌ای سبک برای اصلاح اشتباه رایج «با زبان اشتباه کیبورد تایپ کردم».

## امکانات

- اصلاح متن انتخاب‌شده از منوی راست‌کلیک
- میانبر `Alt + Shift + K`
- تشخیص خودکارِ متن‌های مشکوک بعد از چند کاراکتر
- پشتیبانی از `input`، `textarea` و `contenteditable`
- عدم دستکاری فیلدهای رمز عبور
- بدون سرور و بدون ارسال متن تایپ‌شده به اینترنت

## نکته

تشخیص خودکار عمداً با تأیید کاربر انجام می‌شود تا متن سالم به‌اشتباه تبدیل نشود.
